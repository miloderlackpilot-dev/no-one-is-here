# NO ONE IS HERE

A browser-based psychological interactive fiction prototype.

## Current prototype

- Branching multiple-choice dialogue
- Local session memory
- Hidden response traits
- Minimal monochrome interface
- CRT-style grain and text pacing
- Multiple endings
- No account, analytics, or personal-data collection

The project is intentionally built as fiction. It does not attempt to identify, diagnose, profile, or monitor the player outside the local game session.

## Run

Open `index.html` in a browser or publish the repository with GitHub Pages.
